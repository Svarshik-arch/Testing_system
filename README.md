# Система тестирования

Простая программа для проведения тестов в аудитории по локальной сети.
Два приложения:

- **Преподаватель** (`teacher.py`) — запускается на компьютере преподавателя,
  раздаёт тест, в реальном времени показывает прогресс и выставляет оценки.
- **Студент** (`cadet.py`) — запускается на компьютере студента, проходит тест
  в полноэкранном режиме.

Работает на Windows и не требует интернета — только общая локальная сеть
(один коммутатор/роутер/Wi‑Fi). Дополнительные библиотеки не нужны, нужен
только установленный **Python 3** (скачать: https://python.org, при установке
отметить галочку «Add Python to PATH»).

---

## Как провести тест (коротко)

1. На своём компьютере запустите **`Преподаватель.bat`** (двойной клик).
   - Если файла с вопросами рядом нет — откроется окно выбора файла.
2. Справа в тёмной шапке крупно написан **адрес для студентов**, например
   `192.168.0.10`. Продиктуйте его студентам.
3. Студенты запускают **`Тестирование (студент).bat`**, вводят ФИО, группу и
   этот адрес, нажимают «Подключиться». Адрес программа запоминает.
4. Над таблицей цветные счётчики: сколько студентов ожидают, тестируют,
   завершили, отключены. Когда все подключились — нажмите **«▶ Начать тест»**.
   Опоздавшие начнут тест сразу после подключения.
5. По ходу теста видно, кто сколько ответил, оценку и нарушения.
   **Двойной клик по студенту** — его ответы: что выбрал, верно или нет и
   какой ответ правильный.
6. В конце нажмите **«Сохранить результаты (Excel)»** — сохранится таблица
   CSV, она открывается в Excel. Если закрыть программу, не сохранив
   результаты (или пока тест ещё идёт), она переспросит.

Кнопка **«■ Завершить у всех»** досрочно завершает тест всем сразу — оценка
ставится по уже данным ответам.

## Как выглядит тест у студента

- Вопрос крупным шрифтом, варианты — большие карточки, по ним удобно кликать.
  Можно и с клавиатуры: **1–9** — выбрать вариант, **↑/↓** — переключать,
  **Enter** — ответить.
- Сверху — таймер: синий, за 5 минут до конца жёлтый, в последнюю минуту
  красный. Когда время выходит, ответы отправляются автоматически.
- Полоса прогресса показывает, сколько вопросов уже отвечено.
- Если пропала сеть, тест не закрывается: программа сама переподключится и
  продолжит с того же вопроса (ответы хранятся у преподавателя).

## Оценки

Оценка считается по проценту правильных ответов. Пороги задаются в файле
вопросов в разделе `grading` (проценты):

```json
"grading": { "5": 90, "4": 75, "3": 50 }
```

- ≥ 90 % → **5**
- ≥ 75 % → **4**
- ≥ 50 % → **3**
- меньше → **2**

Если студент выходит из теста досрочно (кнопка «Завершить досрочно») — ставится **2**.
В конце теста студент видит свою оценку и число правильных ответов, если в
файле `show_result: true`. При `show_result: false` он увидит только «Ваши
ответы приняты, оценку сообщит преподаватель».

## Файл с вопросами (`questions.json`)

Обычный текстовый файл, его можно править в «Блокноте». Пример:

```json
{
  "title": "Название теста",
  "time_limit_min": 20,
  "show_result": true,
  "grading": { "5": 90, "4": 75, "3": 50 },
  "questions": [
    {
      "text": "Текст вопроса?",
      "options": ["Вариант 1", "Вариант 2", "Вариант 3"],
      "correct": 1
    }
  ]
}
```

- `title` — название теста.
- `time_limit_min` — ограничение времени в минутах (`0` — без ограничения).
- `show_result` — показывать ли студенту результат (`true`/`false`).
- `grading` — пороги оценок (см. выше).
- `questions` — список вопросов. `correct` — **номер правильного варианта,
  считая с нуля** (0 — первый вариант, 1 — второй и т. д.).

Можно держать несколько файлов (например `математика.json`, `история.json`)
и выбирать нужный при запуске.

## Защита от списывания — что умеет и чего не умеет

**Во время теста:**
- Окно открывается на весь экран поверх всех окон.
- **Системные сочетания клавиш заблокированы** (на Windows): `Win` и все
  сочетания с ней, `Alt+Tab`, `Alt+Esc`, `Ctrl+Esc`, `Alt+F4`, `Alt+Пробел`,
  `Ctrl+Shift+Esc` (Диспетчер задач), клавиша контекстного меню и
  `PrintScreen`. При нажатии студент видит подсказку «Это сочетание клавиш
  недоступно во время теста».
- Крестик и `Alt+F4` окно не закрывают. **Выйти из теста можно только кнопкой
  «Завершить досрочно»** (с подтверждением, оценка 2).
- Если окно всё же потеряло фокус, оно возвращается на передний план, а
  преподаватель видит нарушение в колонке «Нарушения».
- Если у студента пропала связь посреди теста, в колонке «Нарушения»
  появится «обрыв N» — так видно, если кто-то выдёргивал сетевой кабель.

Блокировка сделана через *низкоуровневый хук клавиатуры* (функция Windows
`SetWindowsHookEx`): Windows отдаёт программе каждое нажатие раньше, чем
обработает его сама, и программа может его «съесть». Хук работает только пока
идёт тест. Если программа аварийно закроется, Windows снимет хук сама —
клавиатура не «залипнет».

**Чего не может никакая обычная программа:**
- `Ctrl+Alt+Del` и `Win+L` обрабатывает сама Windows раньше любых программ,
  их заблокировать нельзя. Уход на этот экран засчитывается как нарушение.
- Антивирус может предупредить о программе, которая перехватывает клавиатуру —
  это ожидаемо: так работает блокировка.
- Для полной «киоск»-блокировки (запрет Диспетчера задач, отдельная учётная
  запись) нужны средства Windows: режим киоска или групповые политики.

## Запуск вручную (если нужно)

```
python teacher.py [файл_вопросов.json] [порт]
python cadet.py
```

По умолчанию используется `questions.json` и порт `5050`. Если порт другой,
студенты вводят адрес вместе с ним: `192.168.0.10:5051`.
