# Система тестирования

Простая программа для проведения тестов в аудитории по локальной сети.
Два приложения:

- **Преподаватель** (`teacher.py`) — запускается на компьютере преподавателя,
  раздаёт тест, в реальном времени показывает прогресс и выставляет оценки.
- **Студент** (`cadet.py`) — запускается на компьютере студента, проходит тест
  в полноэкранном режиме.

Работает на Windows и не требует интернета — только общая локальная сеть
(один коммутатор/роутер/Wi‑Fi). Дополнительные библиотеки не нужны, нужен
только установленный **Python 3** (скачать: https://python.org, при установке
отметить галочку «Add Python to PATH»).

---

## Как провести тест (коротко)

1. На своём компьютере запустите **`Преподаватель.bat`** (двойной клик).
   - Если файла с вопросами рядом нет — откроется окно выбора файла.
2. В синей строке сверху будет написан **адрес** вида `192.168.0.10 : 5050`.
   Продиктуйте его студентам.
3. Студенты запускают **`Тестирование (студент).bat`**, вводят ФИО, группу и
   этот адрес, нажимают «Подключиться».
4. Когда все в списке со статусом «Ожидает» — нажмите **«▶ Начать тест»**.
5. По ходу теста видно, кто сколько ответил, оценку и нарушения.
6. В конце нажмите **«💾 Экспорт в CSV»**, чтобы сохранить журнал с оценками
   (открывается в Excel).

Кнопка **«■ Завершить у всех»** досрочно завершает тест всем сразу.

---

## Оценки

Оценка считается по проценту правильных ответов. Пороги задаются в файле
вопросов в разделе `grading` (проценты):

```json
"grading": { "5": 90, "4": 75, "3": 50 }
```

- ≥ 90 % → **5**
- ≥ 75 % → **4**
- ≥ 50 % → **3**
- меньше → **2**

Если студент выходит из теста досрочно (кнопка «Выйти досрочно») — ставится **2**.
В конце теста студент видит свою оценку (если в файле `show_result: true`).

## Файл с вопросами (`questions.json`)

Обычный текстовый файл, его можно править в «Блокноте». Пример:

```json
{
  "title": "Название теста",
  "time_limit_min": 20,
  "show_result": true,
  "grading": { "5": 90, "4": 75, "3": 50 },
  "questions": [
    {
      "text": "Текст вопроса?",
      "options": ["Вариант 1", "Вариант 2", "Вариант 3"],
      "correct": 1
    }
  ]
}
```

- `title` — название теста.
- `time_limit_min` — ограничение времени в минутах (`0` — без ограничения).
- `show_result` — показывать ли студенту результат (`true`/`false`).
- `grading` — пороги оценок (см. выше).
- `questions` — список вопросов. `correct` — **номер правильного варианта,
  считая с нуля** (0 — первый вариант, 1 — второй и т. д.).

Можно держать несколько файлов (например `математика.json`, `история.json`)
и выбирать нужный при запуске.

## Защита от списывания — что умеет и чего не умеет

**Умеет (на уровне приложения):**
- Тест открывается на весь экран поверх других окон.
- Попытка закрыть окно или свернуть его фиксируется: преподаватель видит
  счётчик нарушений в колонке «Наруш.».
- Закрытие окна во время теста = досрочный выход с оценкой 2.

**Важно и честно:** обычная программа на Python **не может полностью**
заблокировать сочетания `Alt+Tab`, клавишу `Windows` и `Ctrl+Alt+Del` — это
уровень операционной системы. Для полной «киоск»-блокировки нужны средства
Windows (режим киоска, групповые политики) или отдельная блокировка
клавиатуры. Текущая защита — честный максимум на уровне приложения:
помешать списыванию и показать преподавателю, кто пытался переключиться.

---

## Запуск вручную (если нужно)

```
python teacher.py [файл_вопросов.json] [порт]
python cadet.py
```

По умолчанию используется `questions.json` и порт `5050`.
